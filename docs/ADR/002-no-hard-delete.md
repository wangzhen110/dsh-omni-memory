# ADR-002：删除语义用墓碑与失效，不做物理删除

- 日期：2026-11-14
- 状态：已采纳

## 背景

记忆系统必须回答"当时我们信什么"。若新事实直接覆盖旧事实，或遗忘即删行，历史不可重建。

## 决策

1. 事实冲突：旧行写 `valid_to`，新行 `valid_to = NULL`，两行并存。
2. 用户遗忘：写 `deleted_at`，检索与画像过滤该行，但行仍可审计。
3. 代码层面不出现 `DELETE FROM`。

## 理由

- Zep/Graphiti 的双时态实践证明：失效比删除更安全，且能回答时间点查询。
- 与 Mem0 的 DELETE 操作形成对照——静默删除是记忆系统最危险的失败模式（记错还能查出来，删掉就永远查不出来）。

## 代价

- 表只增不减，需要未来的归档/压缩策略（尚未实现）。
