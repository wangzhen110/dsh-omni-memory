# ADR-005：界面放左栏导航，不进对话页签

- 日期：2026-11-14
- 状态：已采纳

## 背景

第一版把记忆面板注册进 `conversation.view`，结果它和 对话/轨迹/统计 挤在同一行页签里。用户明确要求"不要放在这里"。

## 决策

1. 注册 `sidebar.panellist`（`id=omni-memory, order=20, label=记忆`）提供左栏入口。
2. 注册 `main`（`key=omni-memory`）渲染面板。
3. 不注册 `conversation.view`。

DSH 的约定是：左栏图标 id 与 `main` 面板 key 相同，二者由同一个 id 配对。

## 理由

- 与 插件 / 自动化任务 同级，符合"全局工具"的心智模型。
- 记忆是跨会话的，放在会话页签里语义不成立。

## 代价

- 面板不受会话上下文约束（不需要）。
