# ADR-006：检索先词面后语义，向量与图分阶段

- 日期：2026-11-14
- 状态：已采纳

## 背景

理想记忆需要语义召回与多跳关联，但两者都引入重依赖（embedding 模型、图算法），且会拖慢首版可用性。

## 决策

分阶段：
1. M0：FTS5 trigram + 中文二元切分 + 分层打分（已实现）。
2. M2：本地 bge-m3 ONNX + `sqlite-vec`，与词面结果用 RRF 融合（FR-17）。
3. M3：实体 PPR 扩散（FR-18）。

阶段间保持接口不变：`memory_search` 的入参出参不因底层算法而变。

## 理由

- HippoRAG 2 的教训：纯图检索会削弱事实召回，必须与词面/向量混合。
- 先有可用的词面召回，才有资格谈语义补强；否则无法判断"变好还是变坏"（需要评测集，D-09）。

## 代价

- 当前换说法查询会漏（已知缺陷 D-01）。
