# ADR-008：嵌入后端可插拔，远程路径惰性刷新

- 日期：2026-11-14
- 状态：已采纳

## 背景

FR-21 要求「换说法也能召回」。哈希 n-gram 做不到（ADR-007 已说明），必须接真语义模型。但插件同时要满足：默认零依赖、不联网、写入不阻塞回合。

## 决策

1. **后端可插拔**：`lib/embed-provider.mjs` 暴露 `backendConfig()`，通过环境变量选择：
   - 无 `OMNI_EMBED_URL` → `hashed`（默认，512 维，同步写入）；
   - 有 `OMNI_EMBED_URL` → `remote`（OpenAI 兼容 `/embeddings`，`OMNI_EMBED_MODEL` / `OMNI_EMBED_KEY`）。
2. **写入只入队，不等待网络**：远程模式下 `indexVector` 把 `(kind,id,text)` 放进内存队列；回合路径零网络调用（NFR-03 不变）。
3. **检索前惰性刷新**：`runSearch` 先 `flushPendingVectors`（每批 ≤32 条），成功后写库并清队列；失败保留队列，检索回退到词面路线。
4. **维度按后端区分**：`vectors.dim` 记录每行维度，检索只取当前后端维度的行；切换后端不需要迁移（旧行自然失效，可按需重建）。
5. **查询侧同后端**：远程模式下查询也用同一端点嵌入，否则空间不一致。

## 验证（`test/semantic.test.mjs`，本地 mock 端点）

| 用例 | 结果 |
|---|---|
| 零共享字符的改写查询（「把界面弄没的坑」→「投影顶掉」） | ✅ 向量路线命中，`lexicalScore` 为空 |
| 同一查询在 hashed 后端 | ✅ 无命中（证明差异真实存在） |
| 端点不可用 | ✅ 不抛错，词面路线照常返回 |

## 代价

- 远程模式首次检索要等一次批量嵌入（≤32 条）；之后命中队列为空则无额外延迟。
- 维度未知前不做向量检索（`activeVectorDim()` 为 0 时直接跳过）。
- 嵌入端点由用户提供，插件默认不联网。
