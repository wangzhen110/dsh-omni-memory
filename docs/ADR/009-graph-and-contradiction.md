# ADR-009：图路线按「遍历到的边」召回；冲突用显式声明 + 相似度启发

- 日期：2026-11-14
- 状态：已采纳

## 背景

FR-18 要求「通过实体边扩散，召回直接匹配不到的相关条目」；FR-19 要求「语义冲突时置 `contested` 并在界面标注」。

两个朴素做法都试过并否掉了：

1. **图路线返回「提到邻居的事实」**：查询 A（A→B）会返回 B 的其他事实（B→C），但再往外一层就变成"提到 C 的事实"（C→D），语义上已经跳脱，且测试证实会越过预期深度。
2. **冲突检测调用模型判断**：每次写入都加一次模型调用，延迟与成本不可接受，且失败会阻塞写入。

## 决策

### 图路线：返回遍历到的边

- 种子：当前 top-6 命中里出现的实体名（`entities` 表子串匹配，带 30 秒缓存，事实写入时失效）。
- 扩散：从种子出发最多 **2 跳**，每跳权重 `0.5^hop`；记录**每条被遍历的边** `(src, rel, dst, weight)`，已访问实体不重复展开。
- 候选：按 `(subject, relation, object)` 精确回查 facts，只返回这些边对应的事实。
- 融合：图路线作为**第三条排名列表**进入 RRF（k=60），与词面、向量并列。
- 开关：`OMNI_DISABLE_GRAPH=1` 关闭。
- 作用域：facts 查询带 scope 过滤，防止跨项目泄漏。

### 冲突：显式声明优先，启发式兜底

- 调用方可用 `memory_write(kind='note', contradicts=[ids])` 明确声明矛盾（只接受存在且未删除的 id）。
- 未声明时，按**哈希向量余弦 ≥ 0.9** 判定近重复/近似矛盾，双方都置 `contested=1`。
- 只标记、不合并、不删除：界面与检索结果都会显示 `contested`，由人复核。

## 验证

- `test/graph.test.mjs`：2 跳内的边可召回；超出跳数不返回；关闭开关后图路线消失；跨作用域不泄漏。
- `test/contradict.test.mjs`：显式声明、近重复自动标记、无关笔记不误伤、未知 id 被忽略。

## 代价与已知局限

- 图路线只覆盖**事实链**。纯笔记语料没有边，因此黄金集上图的增益为 0（实测 MRR 0.927 → 0.927）——这是预期行为，不是缺陷。
- 相似度阈值 0.9 偏保守：实测语义改写对（同一规则两种说法）只有 **0.688**，远低于阈值，所以这类重复不会被标记。降低阈值无效且会误伤，语义重复交给模型复核（ADR-015）或人工清理；0.9 只用于识别字面近似（仅差一个词的对实测 0.913）。
