# ADR-004：常驻注入用单段系统提示 + 1200 字预算 + 30 秒缓存

- 日期：2026-11-14
- 状态：已采纳

## 背景

"记得住"必须体现为模型每轮都能看到，而不是靠模型主动调用工具。但系统提示是稀缺资源，且装配在同步路径上。

## 决策

`systemPrompt.section({ name:'omni-memory', order:600 })`：
- 文本函数同步执行，只读 30 秒缓存；缓存未命中时做一次 `SELECT ... LIMIT 60`。
- 总长 ≤ 1200 字，按 importance 降序填充，超预算的条目整体跳过（不截断半句）。
- 无笔记时返回空串，不产生任何 token。
- `memory_write` 成功后立即失效缓存（FR-10）。

## 理由

- Anthropic 的实践：注入只放少量结论；dsh-memory-openviking 用 1200 字 + 5 分钟缓存验证过可行性。
- 同步读 SQLite 是微秒级，满足 NFR-02/03。

## 代价

- 写入后最迟 30 秒生效（实现为立即），但没有跨进程缓存一致性（单进程无此问题）。
